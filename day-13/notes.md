# Day 13 — SSH + Nginx

## What I learned

- SSH connects my local machine to an EC2 Linux server.
- Amazon Linux uses `ec2-user` as the default SSH user.
- Security Groups control inbound traffic.
- SSH uses TCP port 22.
- HTTP uses TCP port 80.
- Nginx is a web server.
- `systemctl` manages Linux services.
