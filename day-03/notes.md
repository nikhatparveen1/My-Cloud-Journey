## What I Learned

- Linux is operated heavily through the command line.
- pwd shows the current working directory.
- ls lists directory contents.
- cd changes directories.
- touch creates files.
- mkdir creates directories.
- cp copies files.
- mv moves or renames files.
- rm removes files.
- cat displays file contents.
- find searches for files/directories.
- grep searches text.
- A pipe sends one command's output to another command.
- > redirects output and overwrites the destination.
- >> redirects output and appends to the destination.
- man and --help provide command documentation.
