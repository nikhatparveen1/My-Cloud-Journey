# Day 78 — kubectl & EKS Cost Awareness

## Goal

Prepared the local CachyOS environment for Kubernetes
and reviewed the EKS cost model before creating the
cluster.

## Tools

- kubectl
- AWS CLI
- Terraform

## Kubernetes

kubectl is the command-line client used to communicate
with Kubernetes clusters.

## EKS Cost Model

EKS costs include more than Kubernetes commands.

Potential cost sources include:

- EKS control plane
- Worker nodes
- Load Balancers
- EBS/storage
- Other AWS resources

## Safety

No EKS cluster was created during Day 78.

Cluster creation begins only after the Day 80 safety
review.
